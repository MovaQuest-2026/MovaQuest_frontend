# MovaQuest: інтерактивне відео для вивчення мови (робоча назва)

## Продукт
Mobile-first веб-застосунок. Користувач дивиться вертикальну відеоісторію (9:16, інтерфейс як у TikTok). У ключових місцях відео ставиться на паузу, і користувач відповідає голосом. Цільова мова вивчення: іспанська (Іспанія). Мови інтерфейсу: en (за замовчуванням) і uk. Аудиторія 18–30, їдуть в іншу країну на деякий час, мова вже є, її треба освіжити перед поїздкою.

## Правила точки вибору (MVP)
- Рівно 3 результати: correct, wrong, unclear.
- correct веде в основну лінію.
- wrong веде в окрему сюжетну гілку зі своїми сценами. Гілка повертається в основну лінію або закінчується власною кінцівкою.
- unclear веде в спільну сцену «Perdona, ¿puedes repetir?», яка повертає до тієї самої точки вибору (next = '$return'). Після maxRetries невдалих спроб фрази відкриваються автоматично.
- Фрази-підказки сховані за замовчуванням. Кнопка «Show phrases» їх відкриває.
- Відповісти можна голосом або дотиком по картці фрази (після показу).

## Стек
Vite, React 18, TypeScript, react-router-dom, Zustand (з persist), react-i18next, PostHog. Без ігрового рушія, без Phaser, без Ink. Бекенд пізніше (FastAPI на Render, Firebase або Supabase). Зараз усе на моках.

## Архітектура
- Усі дані йдуть через src/api/*.ts. Компоненти не імпортують src/mocks напряму.
- Розпізнавання мови тільки через evaluateSpeech() з src/api. Зараз це мок, потім POST /api/speech/evaluate. Web Speech API як основу не використовуємо.
- Логіка сцен це автомат у features/player/sceneMachine.ts без React, з юніт-тестами.
- Урок описується JSON за типами з src/types/lesson.ts. Кліпи лежать у public/clips/<lessonId>/<clipId>.mp4, ім'я файлу дорівнює id кліпу.

## Лендінг і роути
- `/` — лендінг (src/landing/LandingPage.tsx), лишається в корені. Кнопка «Play the prototype» веде на `/home`.
- `/home` («Головна») одразу відкриває останній незавершений урок (`activeLesson` у useUserStore, продовжує з поточної сцени через `restoreState`), інакше перший урок стрічки. Онбординг теж завершується на `/home`.
- Нижнє меню (TabBar): Головна / Серії / Профіль (хаб уроків в інтерфейсі називається «Серії», роут лишається `/lessons`), є і в плеєрі. Відео стартує одразу, якщо на сторінці вже був жест (`navigator.userActivation`), інакше «Tap to start».
- Стрічка уроків у плеєрі: свайп угору — наступний урок, вниз — попередній (порядок index.json без `comingSoon`; на десктопі коліщатко і ↑/↓). Жести — `useFeedGestures`, сусіди — `useLessonFeed`. Свайпи ігноруються над панеллю вибору й контролами.
- `/onboarding`, `/lessons`, `/lesson/:lessonId`, `/lesson/:lessonId/result`, `/profile`. Сторінки застосунку без пройденого онбордингу редіректять на `/onboarding`.
- Tailwind підключений тільки для лендінгу: landing.css імпортує theme і utilities (без preflight) і сканує тільки src/landing. Глобальні стилі застосунку (src/index.css) лежать у `@layer app`, тож утиліти лендінгу їх перекривають. Нові глобальні стилі теж пишемо в `@layer app`.

## Мобільні вимоги (Android Chrome першим)
- Layout на 100dvh, safe-area insets, без горизонтального скролу.
- <video> з playsinline. Звук вмикається після першого жесту користувача.
- Мікрофон тільки в secure context. Дозвіл просимо після пояснювального екрана.
- Цілі дотику не менші за 44px. Перевіряти на ширині 360px.
- iOS Safari зараз не тестуємо, але Android-only API не використовуємо.

## Конвенції
- Функціональні компоненти з типізованими пропсами. Файли компонентів у PascalCase, утиліт у camelCase.
- Усі тексти інтерфейсу тільки через i18n, без рядків у JSX.
- Тести поруч із файлом, суфікс .test.ts(x).

## Definition of done
npm run lint і npm run build без помилок. Ручна перевірка на 360×800.
