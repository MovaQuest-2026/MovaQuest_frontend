# MovaQuest

Mobile-first веб-застосунок для того, щоб освіжити іспанську перед поїздкою. Користувач гортає короткі вертикальні відео іспанською (як у TikTok). У певний момент відео стає на паузу, і треба сказати наступне слово або відповідь на запитання. Неправильно: ще спроба з підказкою. Завжди можна пропустити. Інтерфейс англійською (за замовчуванням) і українською.

Стек: Vite, React 18, TypeScript, react-router-dom, Zustand, react-i18next, PostHog. Зараз усе працює на моках, бекенду немає. Правила й архітектура описані в [CLAUDE.md](CLAUDE.md).

## Команди

```bash
npm install
npm run dev        # dev-сервер, http://localhost:5173
npm test           # vitest: автомат пауз, перевірка відповідей, протокол TikTok, дані уроків
npm run lint       # oxlint
npm run build      # tsc + vite build у dist/
```

Плейсхолдер-відео для уроків (потрібні `ffmpeg`, `jq` і шрифт DejaVu: `sudo apt install ffmpeg jq fonts-dejavu-core`):

```bash
scripts/make-placeholder-clips.sh            # усі уроки з video.type = "file"
scripts/make-placeholder-clips.sh cafe-madrid
scripts/make-placeholder-clips.sh --debug     # з id уроку й таймером у кадрі, щоб звіряти паузи
```

Скрипт кладе `public/clips/<lessonId>/video.mp4` і `cover.jpg`. На кадрі видно таймер і рядки `cues` у свій час, тож легко перевірити, де стоїть пауза.

### Як додати відео з TikTok

1. Візьми id з посилання: `https://www.tiktok.com/@user/video/7312345678901234567` → `7312345678901234567`.
2. Створи `src/mocks/lessons/<id>.json` з `"video": { "type": "tiktok", "videoId": "7312345678901234567", "author": "user" }` і додай картку в `index.json`.
3. Розстав `cues` і `gaps` за таймінгом відео: `pauseAt` трохи раніше за момент, коли звучить відповідь. Для кожного рядка додай переклад `tr: { en, uk }`, а для `title` і `description` уроку ще й `es`. Рядок субтитрів, видимий у момент паузи, не має містити відповідь ні іспанською, ні в перекладі (`npm test` перевіряє іспанський текст і наявність перекладів).

Плеєр TikTok вбудовується через офіційний Embed Player (`https://www.tiktok.com/player/v1/<id>`) і керується через postMessage. Він шле час рідше, ніж `<video>`, тому між подіями час екстраполюється, а після паузи відео відмотується рівно на межу. Швидкість відтворення для TikTok недоступна. Перевір на реальному відео, що плеєр відповідає на команди: протокол описаний у [tiktokProtocol.ts](src/features/player/video/tiktokProtocol.ts).

### Змінні середовища

Див. [.env.example](.env.example). Без `VITE_POSTHOG_KEY` аналітика вимкнена, і `posthog-js` не потрапляє в бандл (вантажиться окремим чанком лише за наявності ключа).

### Dev-режим розпізнавання

Розпізнавання мови поки мок ([src/api/evaluateAnswer.ts](src/api/evaluateAnswer.ts)). Якщо додати `?dev=1` до адреси (`/lesson/cafe-madrid?dev=1`), угорі з'являється панель `correct / wrong / unclear`: мок повертає вибраний результат. Без вибору: запис менший за 4 КБ дає `unclear`, інакше випадково correct 60%, wrong 30%, unclear 10%. Відповідь текстом перевіряється локально справжнім `matchAnswer()`, без моку.

## Запуск і перевірка на Android

Мікрофон працює лише в secure context (https або `localhost`). Адреса `http://192.168.x.x:5173` ним не є, тож через неї мікрофон не запрацює. Робочих способів два.

**1. USB-налагодження з `adb reverse`.** На телефоні ввімкни «Параметри розробника» → «Налагодження USB» і підключи кабель.

```bash
npm run dev -- --host
adb devices                      # телефон має бути у списку зі статусом device
adb reverse tcp:5173 tcp:5173
```

Відкрий на телефоні Chrome за адресою `http://localhost:5173`. Консоль і мережу телефона видно на комп'ютері в `chrome://inspect/#devices`.

**2. Превʼю-деплой на Vercel.** Після `git push` Vercel збирає превʼю для гілки. Це https, мікрофон працює, посилання можна показати іншим.

### Чекліст ручної перевірки

Перевіряй на Android Chrome або в DevTools з розміром 360×800 (режим пристрою, touch).

- [ ] **Онбординг:** чиста вкладка (або очищений localStorage) → `/onboarding`. Мова перемикає інтерфейс одразу. Після завершення відкривається `/home`.
- [ ] **Пауза:** `cafe-madrid` стає на паузу на 00:05.4x (таймер на кадрі), до «leche». Видно «Un café con _____», лічильник «Try 1 of 3».
- [ ] **Правильна відповідь:** голосом (`?dev=1` → correct) або текстом «leche» / «Leche» / «leshe» → «¡Muy bien!», через ~1.5 с відео продовжується, крапка вгорі зелена.
- [ ] **Неправильна відповідь:** «azúcar» → «Heard «azúcar». Not quite, try again.», «Try 2 of 3», підказка «l _ _ _ _». Після 3-ї помилки відповідь показується сама, потрібно натиснути «Continue».
- [ ] **Нерозбірливо:** `?dev=1` → unclear → «Didn't catch that», лічильник спроб не змінюється.
- [ ] **Пропустити:** «Skip» показує відповідь з перекладом, крапка жовта, «Continue» продовжує відео.
- [ ] **Ще раз:** «Replay» відмотує на 4 с і знову зупиняє на тій самій паузі, спроби зберігаються.
- [ ] **Перемотка:** −5 / +5, дотик по лівій/правій третині і повзунок працюють, але вперед за нерозв'язану паузу (червоні мітки на повзунку) не перемотує.
- [ ] **Мікрофон заборонено:** на паузі одразу відкритий ввід текстом; дотик по мікрофону показує пояснення.
- [ ] **Головна / відновлення:** почни відео, на паузі відповідай неправильно, перейди в «Профіль» і назад у «Головну»: відео стартує за 4 с до тієї ж паузи, лічильник «Try 2 of 3» зберігся.
- [ ] **Стрічка:** свайп угору — наступне відео (`cafe-madrid` → `metro-tips` → `hola-lucia`), вниз — попереднє; на краях екран «пружинить». Свайп над панеллю відповіді не перемикає відео.
- [ ] **Результат:** «2 of 3 right», список слів з бейджами «First try» / «On try 2» / «Skipped», «Next video» і «Try again» працюють. У «Серіях» картка показує «Completed · 2/3».
- [ ] **Субтитри і швидкість:** CC відкриває вибір мов (Español / English / Українська, можна кілька або жодної); 0.75× працює для локальних відео і схований для TikTok.
- [ ] **Теми:** у профілі «Системна / Світла / Темна»; системна йде за налаштуванням телефона й змінюється без перезавантаження. Плеєр і TabBar під відео темні в обох темах.
- [ ] **360×800:** немає горизонтального скролу, кнопки не менші за 44 px, нічого не перекривається safe-area.
