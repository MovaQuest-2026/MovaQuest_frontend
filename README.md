# MovaQuest

Mobile-first веб-застосунок для того, щоб освіжити іспанську перед поїздкою. Користувач гортає стрічку коротких вертикальних відео іспанською (як у TikTok). У певний момент відео стає на паузу, і треба вголос сказати наступне слово, відповісти на запитання або повторити щойно почуте слово. Неправильно — ще спроба з підказкою, завжди можна пропустити.

- **Продакшн:** https://mova-quest-frontend.vercel.app (лендінг на `/`, застосунок на `/app`).
- **Мови інтерфейсу:** English (за замовчуванням), Українська, Español. Субтитри й переклади: es / en / uk.
- **Бекенд:** FastAPI на Render (`https://backend-hb2j.onrender.com`, Swagger на `/docs`): акаунти (email + пароль, Google), профіль, прогрес, лайки й коментарі, розпізнавання мови (Deepgram Nova-3).

## Стек

Vite, React 18, TypeScript, react-router-dom, Zustand (persist), react-i18next, PostHog. Tailwind лише для лендінгу. Деплой фронту на Vercel; `/api/*` проксіюється на бекенд (vercel.json, локально `server.proxy` у vite.config.ts), тож браузер завжди ходить на свій origin.

## Команди

```bash
npm install
cp .env.example .env   # за потреби ввімкни моки, див. «Змінні середовища»
npm run dev            # dev-сервер, http://localhost:5173
npm test               # vitest: автомат пауз, перевірка відповідей, протокол TikTok, дані й медіа уроків, API-шари
npm run lint           # oxlint
npm run build          # tsc + vite build у dist/
```

«Готово» = `npm run lint` і `npm run build` без помилок плюс ручна перевірка на 360×800.

## Відео уроків

12 уроків + заглушка «coming soon». Відео живуть у фронтенді: лежать у git у `public/clips/<lessonId>/` (`video.mp4` + `cover.jpg`), а Vite копіює `public/` у `dist/` без змін, тож кожен білд і деплой містить усі кліпи. Уроки (субтитри й паузи) — JSON у `src/mocks/lessons/`, каталог — `index.json`. Компоненти беруть їх лише через `src/api`.

- Справжні кліпи кодує `scripts/encode-clip.sh` (оригінали в `media/source/`, команди з вирізами в `scripts/build-real-clips.sh`).
- Три уроки (`cafe-madrid`, `metro-tips`, `hola-lucia`) мають плейсхолдер-відео: рядки субтитрів на кольоровому фоні з тихою фоновою музикою (автор у [media/music/CREDITS.md](media/music/CREDITS.md)).

Плейсхолдер-відео (потрібні `ffmpeg`, `jq` і шрифт DejaVu: `sudo apt install ffmpeg jq fonts-dejavu-core`):

```bash
scripts/make-placeholder-clips.sh            # усі уроки з video.type = "file" (перезапише й справжні кліпи!)
scripts/make-placeholder-clips.sh cafe-madrid metro-tips hola-lucia
scripts/make-placeholder-clips.sh --debug cafe-madrid   # з id уроку й таймером у кадрі, щоб звіряти паузи
```

Скрипт кладе `public/clips/<lessonId>/video.mp4` і `cover.jpg`. Без аргументів він проходить усі уроки з `video.type = "file"`, зокрема зі справжніми кліпами, тож передавай id явно.

### Як додати урок з власним відео

Повний покроковий процес (таймінги, вирізання очікувань, паузи, перевірки) описаний у [docs/adding-videos.md](docs/adding-videos.md). Нижче коротка версія.

Для публічного запуску — тільки власні або ліцензовані кліпи; чужі відео з TikTok не викачуємо, для них є тип `tiktok` (див. нижче). Частина нинішніх кліпів узята з чужих відео для демо, це відомий ризик (див. [docs/project-context.md](docs/project-context.md)).

1. Закодуй кліп (потрібен `ffmpeg`):

   ```bash
   scripts/encode-clip.sh ~/Videos/raw/barista.mov cafe-madrid
   scripts/encode-clip.sh --cover-at 3 --crf 25 ~/Videos/raw/metro.mp4 metro-tips
   ```

   Скрипт робить 720×1280 (9:16; горизонтальне відео обрізається по центру, без чорних смуг), до 30 fps, H.264 High + AAC з `faststart` і кладе `video.mp4` та `cover.jpg` (кадр на `--cover-at` секунді, за замовчуванням 1) у `public/clips/<lessonId>/`. Наприкінці друкує тривалість і готові рядки для JSON. Якщо файл більший за 8 МБ, попереджає: підвищ `--crf` (менша якість) або вкороти кліп.

2. Створи `src/mocks/lessons/<lessonId>.json` з `"video": { "type": "file", "src": "/clips/<lessonId>/video.mp4" }`, `"cover": "/clips/<lessonId>/cover.jpg"` і `durationSec` з виводу скрипта. Додай картку в `index.json` з тим самим `cover`.
3. Розстав `cues` і `gaps` (правила ті самі, що й для TikTok, див. крок 3 нижче).
4. `npm test`. [scripts/clips.test.ts](scripts/clips.test.ts) перевіряє, що кожна обкладинка з `index.json` і кожне відео та обкладинка з уроків існують у `public/`, а в mp4 метадані (`moov`) стоять перед даними (`mdat`), тобто кліп закодований з `faststart`.

Чому це важливо:

- **`faststart`.** Без нього браузер не почне грати і не перемотає («Ще раз», стрілки слів, затиснута перемотка), поки не завантажить файл до кінця. На мобільному інтернеті це помітно.
- **Відсутній файл.** У [vercel.json](vercel.json) усі шляхи, крім `/clips/`, переписуються на `index.html` (SPA-роутинг). Тому відсутній кліп дає справжній 404, а не HTML зі статусом 200, але в браузері це все одно видно лише як порожній плеєр. Тест ловить таку помилку раніше.
- **Розмір.** Кожна версія кожного mp4 назавжди лишається в історії git. Перекодовуй кліп рідко, а чернетки тримай поза репозиторієм.
- **Кеш.** Файли в `public/` не мають хешу в імені. Якщо замінити відео під тим самим іменем, браузер може якийсь час показувати стару версію. Для MVP це не критично; якщо стане проблемою, називай файли з версією (`video.v2.mp4`).

### Коли відео стане забагато для git

Зараз вирішено, що відео й уроки лишаються на фронтенді (бекенд їх не зберігає). Коли репозиторій стане завеликим, відео й обкладинки переїдуть у сховище (S3/R2 тощо). Міграція: завантажити вміст `public/clips/` у бакет і змінити URL-и в JSON уроків (або тіла `getLesson()` / `getLessons()` у `src/api`). Тип `Lesson` і компоненти не змінюються, бо `video.src` і `cover` уже є URL-рядками.

### Як додати відео з TikTok

1. Візьми id з посилання: `https://www.tiktok.com/@user/video/7312345678901234567` → `7312345678901234567`.
2. Створи `src/mocks/lessons/<id>.json` з `"video": { "type": "tiktok", "videoId": "7312345678901234567", "author": "user" }` і додай картку в `index.json`.
3. Розстав `cues` і `gaps` за таймінгом відео: `pauseAt` трохи раніше за момент, коли звучить відповідь. Для кожного рядка додай переклад `tr: { en, uk }`, а для `title` і `description` уроку ще й `es`. Рядок субтитрів, видимий у момент паузи, не має містити відповідь ні іспанською, ні в перекладі (`npm test` перевіряє іспанський текст і наявність перекладів).

Плеєр TikTok вбудовується через офіційний Embed Player (`https://www.tiktok.com/player/v1/<id>`) і керується через postMessage. Він шле час рідше, ніж `<video>`, тому між подіями час екстраполюється, а після паузи відео відмотується рівно на межу. Швидкість відтворення для TikTok недоступна. Перевір на реальному відео, що плеєр відповідає на команди: протокол описаний у [tiktokProtocol.ts](src/features/player/video/tiktokProtocol.ts).

## Змінні середовища

Див. [.env.example](.env.example). Vite читає їх лише на старті.

| Змінна | Що робить |
|---|---|
| `VITE_API_PROXY_TARGET` | куди dev-сервер проксіює `/api` (порожньо — Render, локальний бекенд — `http://localhost:8000`) |
| `VITE_MOCK_SPEECH` | `true` — мок розпізнавання без бекенду |
| `VITE_MOCK_SOCIAL` | `true` — мок лайків, збережень, лічильників і коментарів |
| `VITE_SOCIAL_SEED` | `true` (за замовчуванням) — до справжніх лічильників і коментарів додається мок-база з `src/mocks/social` |
| `VITE_MOCK_PROFILE` | `true` — профіль з онбордингу в localStorage замість `/api/v1/me/profile` |
| `VITE_MOCK_PROGRESS` | `true` — прогрес у localStorage замість `/api/v1/me/progress` |
| `VITE_POSTHOG_KEY`, `VITE_POSTHOG_HOST` | аналітика; без ключа вимкнена, і `posthog-js` не вантажиться |

Google-вхід ключів на фронті не потребує: це redirect-flow бекенду (`/api/v1/auth/oauth/google`), client ID і secret живуть на Render. Щоб він працював, на бекенді має бути правильний `OAUTH_REDIRECT_BASE_URL`, а в Google Cloud — redirect URI домену фронту (див. [docs/backend-plan.md](docs/backend-plan.md)).

Безкоштовний Render засинає: перший запит після простою довгий. Фронт заздалегідь «будить» його запитом `GET /api/health`.

## Dev-режим розпізнавання

З `VITE_MOCK_SPEECH=true` розпізнавання працює без бекенду ([src/api/evaluateAnswer.ts](src/api/evaluateAnswer.ts)). Якщо додати `?dev=1` до адреси (`/lesson/cafe-madrid?dev=1`), угорі з'являється панель `correct / wrong / unclear`: мок повертає вибраний результат. Без вибору: запис менший за 4 КБ дає `unclear`, інакше випадково correct 60%, wrong 30%, unclear 10%. З реальним бекендом панель нічого не змінює. Відповідь текстом завжди перевіряється локально справжнім `matchAnswer()`.

## Запуск і перевірка на Android

Мікрофон працює лише в secure context (https або `localhost`). Адреса `http://192.168.x.x:5173` ним не є, тож через неї мікрофон не запрацює. Робочих способів два.

**1. USB-налагодження з `adb reverse`.** На телефоні ввімкни «Параметри розробника» → «Налагодження USB» і підключи кабель.

```bash
npm run dev -- --host
adb devices                      # телефон має бути у списку зі статусом device
adb reverse tcp:5173 tcp:5173
```

Відкрий на телефоні Chrome за адресою `http://localhost:5173`. Консоль і мережу телефона видно на комп'ютері в `chrome://inspect/#devices`.

**2. Превʼю-деплой на Vercel.** Після `git push` Vercel збирає превʼю для гілки. Це https, мікрофон працює, посилання можна показати іншим.

### Чекліст ручної перевірки

Перевіряй на Android Chrome або в DevTools з розміром 360×800 (режим пристрою, touch). Для перевірки без бекенду вистачить `VITE_MOCK_SPEECH=true` і `?dev=1`.

- [ ] **Старт:** `/app` одразу відкриває закріплене відео (`breaking-bad`) і грає без звуку з кнопкою «Увімкнути звук»; перший дотик будь-де вмикає звук.
- [ ] **Пауза:** `cafe-madrid` стає на паузу на ~5.5 с, до «leche». Видно «Un café con _____» і «Спроба 1 з 3».
- [ ] **Правильна відповідь:** голосом (`?dev=1` → correct) або текстом «leche» / «Leche» / «leshe» → «¡Muy bien!», відео продовжується, крапка вгорі зелена.
- [ ] **Неправильна відповідь:** «azúcar» → «Почули «azúcar»…», наступна спроба й підказка «l _ _ _ _». Після останньої помилки відповідь показується сама, далі «Далі».
- [ ] **Нерозбірливо:** `?dev=1` → unclear → прохання повторити, лічильник спроб не змінюється.
- [ ] **Пропустити / Ще раз:** «Пропустити» показує відповідь з перекладом; «Ще раз» відмотує на 4 с і знову зупиняє на тій самій паузі.
- [ ] **Повтор слова (`repeat`):** у `shrek-burro` пауза стоїть одразу після слова («noche», «gracias», «divertido», «mañana»), підказка відкрита.
- [ ] **Навігація:** дотик будь-де — пауза, подвійний дотик — лайк (гостя веде на `/auth`). Стрілки біля повзунка переходять на попереднє/наступне слово й не перескакують близькі. Затиснутий лівий/правий край перемотує назад/вперед, вперед зупиняється перед нерозв'язаним словом, після відпускання пауза не ставиться.
- [ ] **Мітки:** перемотані вперед паузи стають червоними; кнопка над відео пропонує спробувати слово ще раз (червоне) або повторити (зелене, результат не погіршується).
- [ ] **Мікрофон заборонено:** на паузі одразу відкритий ввід текстом.
- [ ] **Відновлення:** почни відео, на паузі відповідай неправильно, перейди в «Профіль» і назад: відео продовжується з тієї ж паузи, номер спроби зберігся.
- [ ] **Стрічка:** свайп угору — наступне відео, вниз — попереднє; після останнього знову перше. Свайп над панеллю відповіді не перемикає відео.
- [ ] **Підсумок:** модальне вікно з рахунком і компактним списком слів (фраза · переклад, бейдж праворуч); «Спробувати ще раз» і «Наступне відео» працюють.
- [ ] **Субтитри й швидкість:** CC відкриває вибір мов (кілька або жодної); `1×` відкриває повзунок 0.5–1.5×; для TikTok кнопки швидкості немає.
- [ ] **Профіль (гість):** одна картка «Увійти», без блоку прогресу. Групи «Відео / Вигляд / Мікрофон»; субтитри мультиселектом, швидкість повзунком, тема картками з мініатюрою.
- [ ] **Вхід:** email + пароль або Google → онбординг (мова, рівень, мета) → повернення до відео. У профілі з'являються «Навчання» і «Прогрес».
- [ ] **Теми:** системна йде за налаштуванням телефона й змінюється без перезавантаження. Плеєр і TabBar під відео темні в обох темах.
- [ ] **360×800:** немає горизонтального скролу, кнопки не менші за 44 px, верхня панель плеєра вміщається навіть з 12 словами (`words-quiz`), нічого не перекривається safe-area.
